## 🚀 Featured Projects

### 🩸 LifeStream – Blood Bank Management System

A full-stack blood bank management application built with **Java and Spring Boot**.

🔗 [GitHub Repository](https://github.com/Saaagar09/BloodBankManagementSystem)
🌐 [Live Demo](https://bloodbank-frontend-5rkx.onrender.com/)

**Key Features:**

* 🔐 JWT-based authentication using Spring Security
* 👥 USER and ADMIN role-based authorization
* 🩸 Donor and blood request management
* 🔄 CRUD operations through REST APIs
* 🛡️ BCrypt password hashing
* ✅ DTO-based validation and entity mapping
* 🚫 Ownership-based access control for users
* ⚠️ Global exception handling
* 🗄️ Spring Data JPA with MySQL
* ☁️ Backend deployed on Render
* 🗃️ MySQL database hosted on Aiven

**Tech Stack:**
`Java` `Spring Boot` `Spring Security` `Spring Data JPA` `MySQL` `JWT` `REST API`
